# Data Strategy & Provenance Architecture

## 1. Multi-Layered Government Data Strategy
LegalMet Verify implements strict source provenance tracking to guarantee data integrity, prevent synthetic hallucination, and preserve legal authenticity:

```
┌────────────────────────────────────────────────────────────────────────┐
│ Layer A: DoCA Model Approval (Central Reference Standards)             │
│ • Sourced from Department of Consumer Affairs Model Approval Orders   │
│ • Contains manufacturer, brand, accuracy class, capacity, interval 'e'│
│ • Source Tag: DOCA_MODEL_APPROVAL                                      │
├────────────────────────────────────────────────────────────────────────┤
│ Layer B: State Legacy Verification Scans (Field Reality Baseline)      │
│ • Sourced from State Legal Metrology Portals (e.g. Jharkhand Barhi)    │
│ • Contains historical certificate scans, trader names, fees, areas     │
│ • Source Tag: GOVERNMENT_PORTAL / OCR (Pending Human Review)           │
├────────────────────────────────────────────────────────────────────────┤
│ Layer C: Live Platform Records (Operational Verification Cycle)        │
│ • Generated by verified traders, scrutinized by admins, tested by LMOs│
│ • Contains GPS coordinates, timestamps, photos, calculated MPE errors │
│ • Source Tag: MANUAL / DEMO_DATA                                       │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Core Provenance Rules
1. **Never Manufacture Records:** Every record in the database must originate from an identifiable source layer (`DOCA_MODEL_APPROVAL`, `GOVERNMENT_PORTAL`, `OCR`, `MANUAL`, `DEMO_DATA`). Missing fields remain `NULL`.
2. **Raw OCR Fidelity:** Raw OCR text extracted by Tesseract must be preserved unaltered alongside the original source PDF/image filename.
3. **No Automatic Legal Authority for OCR:** Scanned legacy certificates remain marked `manual_verified = FALSE` with confidence scores until explicitly scrutinized and confirmed by an authorized officer.
4. **Transparent Rule Citations:** Every pass/fail determination must cite the exact legal clause (e.g. *Legal Metrology (General) Rules, 2011 - Seventh Schedule, Part-II*). Unverified rules are explicitly stamped as `DEMO RULE — NOT FOR LEGAL USE`.
